# ADA

**ADA** is a Windows app for working with Claude Code (and your own local AI models) across your PCs.
This repository only holds the **installers**. Get the latest from **[Releases](https://github.com/Volatile111/ada-releases/releases/latest)**.

## What it does

- Claude Code sessions with approvals, diffs, a changes panel, git, schedules and usage tracking, across several Claude accounts.
- Your other PCs: pair them and let a session work on them.
- Local AI ("Local ADA"): chat with a model on your own graphics card, give it folders and web access, and let Claude hand it coding tasks. Free and private (uses [Ollama](https://ollama.com)).
- A phone app (iPhone and Android) through Tailscale.

## Install

1. Download `ADA-Setup-<version>.exe` from the latest release and run it.
2. Windows may say **"Windows protected your PC"** because the installer isn't code-signed yet: click **More info → Run anyway**.
3. Follow **Getting started** on ADA's start screen: sign in to Claude, start a session, and optionally set up a local AI (Settings → Local AI).

ADA checks this page for updates and installs them for you (Settings → Updates).
